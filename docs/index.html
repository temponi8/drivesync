DriveSync

Two-way Google Drive folder sync for Ubuntu, similar to the "Mirror files" mode of Google Drive for desktop on Windows.

Local folder on Ubuntu  ⇄  Google Drive  ⇄  your other computers

What it does

  • Uploads changes a few seconds after you save a file in the synced folder.
  • Checks Google Drive every few minutes and downloads changes made elsewhere.
  • Keeps both copies when the same file was edited in two places, so nothing is silently overwritten.
  • Refuses to propagate mass deletions without your confirmation.
  • Shows its status in a GNOME tray icon and starts automatically at login.

How it works

DriveSync is a small open-source Python program that runs on your own computer. File transfers are done by rclone bisync, using a Google sign-in that you authorize yourself. There is no DriveSync server: your files go directly between your computer and your Google Drive.

Install

sudo apt install -y python3-venv python3-watchdog python3-gi gir1.2-ayatanaappindicator3-0.1 unzip curl
curl -fsSL https://rclone.org/install.sh | sudo bash
git clone https://github.com/temponi8/drivesync.git ~/drivesync && cd ~/drivesync
python3 -m venv --system-site-packages .venv
.venv/bin/pip install -e .
.venv/bin/drivesync setup
